# 🤖 Gemini-Ai — AI Chat Interface (Frontend)

A **Gemini-style AI chat interface** in vanilla JavaScript — chat list, typing form, suggestion cards, light/dark theme toggle and delete-chat flow.

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-0D1117?style=for-the-badge&logo=javascript&logoColor=F7DF1E)

## Inside
- `script.js` — the chat UI logic: message flow, generating state, theme switching, suggestion prompts

## Note
This is the **frontend logic** of the chat experience. To make it answer, connect it to the Google Gemini API with your own API key in your own deployment — never publish your key in a public repo.
